# Run SEO Pass — James Gorman Property

Use this file for any recurring James Gorman SEO drafting pass, including cron-triggered runs.

## Objective
Run a safe, repeatable SEO working session for James Gorman Property.

## Hard rules
- **Draft only. Do not publish.**
- **Do not make any public/external changes** without Phil's explicit go-ahead.
- **Update documentation every run**.

## Files to review first
1. `README.md`
2. `backlog.md`
3. Latest entries in `seo-changelog.md`
4. `weekly-report-template.md` if a weekly report is being prepared
5. Latest deliverables in this folder if continuing a previous pass

## Recurring workflow

### 1) Review state
- Read the current backlog and latest changelog notes.
- Identify the highest-priority unfinished SEO items.
- Respect priority order: website technical SEO -> GBP -> citations/content.

### 2) Inspect current situation
Where possible, review:
- current website pages and technical issues
- indexation/search visibility clues
- metadata / H1 / internal link gaps
- local presence / GBP status
- citation opportunities
- competitor movement in Derry / Limavady / Eglinton / Dungiven

### 3) Draft next outputs
Prepare one or more of the following:
- technical SEO fix memo
- page title/meta/H1 drafts
- slug recommendations
- internal linking recommendations
- content brief or FAQ ideas
- GBP setup/checklist draft
- citation target list
- weekly report draft

### 4) Update records
Append a dated entry to `seo-changelog.md` with:
- what was reviewed
- what was drafted
- what was found
- blockers / decisions

Update `backlog.md` with:
- completed items
- new TODOs
- reordered priorities
- explicit next actions

### 5) Friday reporting step
If the run is for the weekly report:
- use `weekly-report-template.md`
- summarise changelog activity from the week
- include Ahrefs metrics if accessible
- include ranking / visibility movement
- include technical fixes completed
- include content drafted
- include next actions and any early uplift
- state clearly when data access was unavailable

## Recommended output format
For each recommendation include:
- **What**
- **Why it matters**
- **Priority** (`P1`, `P2`, `P3`)
- **Owner** (`Phil publish`, `Needs client input`, `Draft only`)
