## 4) Internal linking approach
### Core rule
Every new page should link back into the money pages.

### Main hub links
Homepage should link prominently to:
- Sales
- Lettings
- Property Search
- Free Valuation
- Contact
- Areas we cover

### Location page links
Each location page should link to:
- Sales page
- Lettings page
- Valuation page
- Contact page
- Property search page

### Blog links
Every article should link to one or more of:
- `/free-property-valuation-derry`
- `/sales-derry`
- `/lettings-derry`
- relevant location page

Example:
- article about selling in Limavady → link to `/estate-agent-limavady` and `/free-property-valuation-derry`
- landlord article → link to `/lettings-derry`
