# James Gorman Property — Friday Report Draft Workflow
**Owner:** Blue Canvas / Phil Patterson  
**Status:** Draft-only workflow

## Purpose
Prepare a clean Friday SEO report draft for James Gorman Property every week at **14:00 Europe/London**.

## Brand / tone
- Clear, direct, useful
- No fluff
- Commercially focused
- Honest about missing data
- Draft only — never publish or send externally without Phil reviewing

## Inputs to review every Friday
1. `README.md`
2. `backlog.md`
3. `seo-changelog.md`
4. `weekly-report-template.md`
5. Latest James deliverables from the current week
6. Ahrefs / GSC / GA4 data if available

## Output must cover
- activity changelog
- Ahrefs metrics
- ranking movement / visibility changes
- technical fixes completed
- content drafted
- blockers
- next actions
- any uplift / early movement

## Friday pass checklist
### 1) Review weekly activity
- Pull the week’s completed drafts and findings from `seo-changelog.md`.
- Separate what was researched, what was drafted, and what Phil still needs to publish.

### 2) Pull visibility data
If accessible, capture:
- Ahrefs DR
- referring domains
- backlinks
- organic keywords
- organic traffic estimate
- notable ranking changes for target pages/terms

If data is inaccessible:
- say so clearly
- do not invent numbers

### 3) Summarise technical work
Capture:
- fixes drafted
- fixes published if known
- unresolved technical issues
- current blockers to progress

### 4) Summarise content work
Capture:
- page drafts created
- metadata/slugs prepared
- location pages/content strategy drafted
- articles or briefs prepared

### 5) Set next actions
Always finish with 3 practical next moves, ideally split by:
- Phil publish
- agent draft next
- client input needed

## Mandatory notes
- Keep the line clear between **drafted** and **published**.
- Never imply a live change happened unless it definitely did.
- Never publish, submit, or update public assets from the Friday run.
- Update `backlog.md` and `seo-changelog.md` before finishing.
