## 4. Landing Page Recommendations (Quality Score Optimisation)

### Critical Elements for openclawconsultant.co.uk

#### Above the Fold (Hero Section)
- **Headline:** "We Build AI Agents That Run Your Business" (matches ad messaging)
- **Sub-headline:** "From £1,500 — deployed in days, not months"
- **Primary CTA:** Large button → "Book Your Free Strategy Call" (Calendly embed)
- **Trust signal:** "50+ AI agents deployed for UK businesses"
- **Hero visual:** Screenshot/demo of an OpenClaw agent in action

#### Quality Score Factors (Google's Scoring)

1. **Keyword-Ad-Landing Page Alignment (Critical)**
   - H1 must include primary keywords ("AI Agent", "OpenClaw", "Consultant")
   - Page copy must mirror ad group themes
   - Create 3 landing page variants — one per ad group for maximum relevance

2. **Page Speed (Target: <3s mobile load)**
   - Minimal JavaScript, optimised images (WebP)
   - No heavy frameworks — static HTML or lightweight build
   - Core Web Vitals: LCP <2.5s, FID <100ms, CLS <0.1
   - Test with PageSpeed Insights — aim for 90+ mobile score

3. **Mobile Experience (60%+ of clicks will be mobile)**
   - Responsive design, tap-friendly buttons (min 48px)
   - Calendly embed must work perfectly on mobile
   - Click-to-call button for mobile users

4. **Content Requirements**
   - **What you do:** Clear explanation of AI agent services
   - **How it works:** 3-step process (Book Call → We Build → You Automate)
   - **Social proof:** Case studies, testimonials, logos
   - **Pricing anchor:** "From £1,500" visible above fold
   - **FAQ section:** Addresses common objections
   - **Trust signals:** Based in Derry NI, real person (Phil Patterson), company registration

5. **Conversion Optimisation**
   - Single CTA throughout — Calendly booking
   - Exit-intent popup with lead magnet ("Free AI Readiness Audit")
   - Calendly embed (not link) below the fold for easy booking
   - Form alternative: Name + Email + "What do you want to automate?" field
   - WhatsApp chat widget as secondary conversion path

6. **Technical SEO**
   - SSL (HTTPS) — mandatory
   - Proper meta title/description matching ad themes
   - Schema markup (LocalBusiness, Service)
   - No intrusive interstitials

## 9. Key Risks & Mitigations

| Risk | Impact | Mitigation |
|------|--------|------------|
| OpenClaw terms have very low volume initially | Low spend, fewer leads | Service + Local groups carry the weight |
| AI agent CPCs rising fast (competitive market) | Higher CPL | Lock in brand terms early at low CPC |
| Landing page not ready | Can't launch | Build simple, fast page — don't over-engineer |
| Calendly no-shows | Wasted leads | Add email reminder sequence, SMS confirmation |
| Broad match keyword bleed | Wasted spend | Start exact + phrase only, review search terms weekly |
| Google's AI Overviews reducing CTR | Fewer clicks | Use ad extensions aggressively, bid on exact match |
