### Conversion Tracking Setup (for Niall)

**Primary Conversion: Calendly Booking**

Option A — Calendly redirect:
1. In Calendly, set confirmation to redirect to: `https://bluecanvas.ai/thank-you`
2. On `/thank-you` page, fire the Google Ads conversion tag

Option B — Calendly webhook:
1. Use Calendly's JavaScript API to detect booking completion
2. Fire `gtag('event', 'conversion', {...})` on booking

**Google Tag to add to ALL pages (Webflow custom code → Head):**

```html
<!-- Google tag (gtag.js) -->
<script async src="https://www.googletagmanager.com/gtag/js?id=AW-XXXXXXXXX"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());
  gtag('config', 'AW-XXXXXXXXX');
</script>
```

*(Replace AW-XXXXXXXXX with the conversion ID from Google Ads → Tools → Conversions)*

**Conversion tag for thank-you page only:**

```html
<script>
  gtag('event', 'conversion', {
    'send_to': 'AW-XXXXXXXXX/YYYYYYYYYY',
    'value': 100.0,
    'currency': 'GBP'
  });
</script>
```

**Phone click tracking (all pages):**

```html
<script>
  document.querySelectorAll('a[href^="tel:"]').forEach(function(el) {
    el.addEventListener('click', function() {
      gtag('event', 'conversion', {
        'send_to': 'AW-XXXXXXXXX/ZZZZZZZZZZ',
        'value': 50.0,
        'currency': 'GBP'
      });
    });
  });
</script>
```
