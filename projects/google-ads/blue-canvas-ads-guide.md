# Google Ads Setup Guide — Blue Canvas AI
## £20/Day Campaign | High-Intent Keywords Only

**Goal:** Get Blue Canvas in front of people actively searching for AI help RIGHT NOW.
**Budget:** £20/day = ~£600/month
**Expected:** 8-15 clicks/day → 2-4 leads/week → 1-2 consultations/week

---

## Step 1: Create Your Campaign (10 mins)

1. Go to [ads.google.com](https://ads.google.com)
2. Sign in with your Google account
3. Click **"New Campaign"**
4. Select **"Leads"** as your goal
5. Select **"Search"** as campaign type
6. Name it: `Blue Canvas — AI Consultancy`
7. Set budget: **£20/day**
8. Bidding: **Maximise conversions** (let Google optimise)
9. Location targeting: **United Kingdom** + **Ireland**
   - Also add: **Northern Ireland** as a specific target with bid boost (+20%)
10. Language: **English**

## Step 6: Conversion Tracking

Set up these conversion actions in Google Ads:

1. **Primary:** Form submission on /lp/free-ai-consultation (or /contact)
2. **Secondary:** Phone call clicks (if phone number on site)
3. **Secondary:** Email link clicks

To set up:
1. Go to Google Ads → Tools → Conversions
2. Click "New conversion action"
3. Select "Website"
4. Enter bluecanvas.ai
5. Set up the tag (Google Tag Manager or direct install)
