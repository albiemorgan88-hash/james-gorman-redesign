# Nightly Build — 2026-02-11

## Outreach Forge — Email Template Builder

**What:** A local outreach email generator tailored for Blue Canvas sales. Pick a template type (cold intro, follow-up, referral, re-engage, post-event, value add), fill in prospect details, choose your tone, and get a ready-to-send email in seconds.

**Why:** PJ's pipeline depends on consistent outreach — Apollo.io, LinkedIn, Loom pitches. This tool removes the blank-page problem and keeps messaging on-brand.

## Features
- **6 email types** — Cold, Follow-up, Referral, Re-engage, Post-Event, Value Add
- **4 tone options** — Casual, Professional, Bold, Warm
- **12 industry sectors** with tailored value propositions
- **Smart placeholders** — highlights anything that needs manual editing
- **Copy to clipboard** — one click, paste into Gmail/Apollo
- **Save & recall** — localStorage-backed template library
- **Preview & raw text** views

## How to Use
1. Open `index.html` in any browser
2. Pick your template type and tone
3. Fill in contact name, company, industry, and the specific hook/pain point
4. Hit **Generate Email →**
5. Review, tweak, copy, send
