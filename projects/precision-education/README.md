# Precision Education Website

Ultra-minimalist single-page site for Precision Education (Ian Patterson).

## Pages
- **Home** — Overview of Precision Education
- **Our Work** — Services and examples
- **Our Team** — About Ian Patterson
- **Contact** — Email contact

## Design
- Single HTML file (`index.html`), no dependencies
- White background, black text, Georgia serif font
- Hash-based navigation, mobile responsive
- No self-promotion, no upselling — per Ian's brief

## Deployment
Static HTML — host anywhere. Single file, no build step.
