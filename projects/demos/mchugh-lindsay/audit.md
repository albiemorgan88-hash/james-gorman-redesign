# SEO Audit - McHugh Lindsay

## Overall Score: 20/100

### Issues Found

#### Critical Issues (Immediate Impact)
1. **Missing Meta Descriptions (0/10 points)**
   - Homepage has no meta description
   - About page missing description
   - Google can't understand page content

2. **No Local SEO Setup (0/10 points)**
   - No Google Business Profile found
   - Missing NAP (Name, Address, Phone) consistency
   - Not appearing in "consultancy Derry" searches

3. **Minimal Content Depth (3/15 points)**
   - Homepage has brief content
   - No service-specific pages
   - Insufficient content to rank for target keywords

#### Technical Issues
4. **Missing Schema Markup (0/15 points)**

   - Missing structured data entirely

5. **Poor Page Titles (5/10 points)**

   - Missing compelling CTAs

#### Moderate Issues
6. **Limited Content Strategy (2/15 points)**

   - Missing case studies or testimonials

7. **Basic Technical Setup (8/15 points)**

8. **Social/Open Graph (2/5 points)**

## Recommendations for Improvement

- Add compelling meta descriptions to all pages
- Create and claim Google Business Profile
- Optimize page titles for local searches

### Medium-term (Weeks 2-4) 
- Add LocalBusiness schema markup
- Create service-specific landing pages
- Develop case studies and testimonials

### Long-term (Months 2-3)
- Launch thought leadership blog
- Build local citation profile
- Develop content marketing strategy
