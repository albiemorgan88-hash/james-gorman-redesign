1. **Set up CRM** → Read `crm-tracker.md`, create the Google Sheet (10 mins)

4. **Pick your templates** → `email-templates.md` + `linkedin-templates.md`

## Target Numbers

- **Daily:** 5 new contacts (email + LinkedIn)
- **Weekly:** 25 contacts → 5-8 replies → 2-3 calls → 1 proposal
- **Monthly:** ~2-3 new clients at £200-350/mo each
- **Goal:** 10 clients = ~£2,750/mo recurring (+ James Gorman's £250 = £3,000/mo)

## The System

```
Local Scraper / Apollo → Lead Scoring → Showcase Build → Email + LinkedIn → Follow-up → Call → Proposal → Close
```

Every step has a template. Every template has placeholders. Fill in the blanks, send, track, repeat.
