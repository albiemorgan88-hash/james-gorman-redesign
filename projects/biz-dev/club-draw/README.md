# ClubDraw Business Development Project

## 🎯 Mission
Scale Ardmore's £195/week success to 10+ more clubs across NI/Ireland. Target: £2k/week recurring platform revenue.

## 📊 Current Status
- **Live Clubs:** 1 (Ardmore CC)
- **Weekly Revenue:** £19.50 platform fee (10% of £195)
- **Proof of Concept:** ✅ Established

## 🎲 The Model
- Members pick 5 numbers (1-50) for £1 each/week
- Weekly draw every Friday 8pm
- Club gets 90%, ClubDraw gets 10%
- Fully automated via Stripe + WhatsApp
- Society lottery compliant (NI law)
