# Blue Canvas AI — LinkedIn Message Templates

---

## 1. Connection Request Note (under 200 chars)

### Version A — Local angle
```
Hi [FIRST_NAME] — fellow Derry business owner here. I run Blue Canvas AI, helping local businesses get found on Google. Would be great to connect!
```

### Version B — Sector angle
```
Hi [FIRST_NAME] — I work with [SERVICE_TYPE] businesses on their Google visibility. Noticed [BUSINESS_NAME] and thought I'd connect. Phil from Blue Canvas AI.
```

### Version C — Mutual connection
```
Hi [FIRST_NAME] — [MUTUAL_CONNECTION] mentioned [BUSINESS_NAME]. I help Derry businesses with SEO and AI. Would love to connect!
```

## 3. Follow-Up Message (1 week after first message, no response)

```
Hi [FIRST_NAME] — hope you're well!

Just wanted to flag: [SPECIFIC_INSIGHT — e.g. "I noticed [COMPETITOR] just updated their site and they're now ranking above [BUSINESS_NAME] for [KEY_TERM]"].

The offer still stands for a free 15-min review — happy to walk through what I found.

https://calendly.com/contact-bluecanvas/initial-consultation

No pressure either way. Cheers!

```

---

## Rules

1. **Never send connection + message at the same time.** Connect first. Message after they accept.
2. **One follow-up max.** If they don't respond to the follow-up, leave it. Don't be that guy.
3. **Engage with their content first.** Like/comment on 2-3 of their posts before connecting. Warms them up.
4. **Keep it conversational.** This is LinkedIn, not email. Write like you'd text a colleague.
5. **Max 5 new connections per day.** LinkedIn flags accounts that spam connections.
