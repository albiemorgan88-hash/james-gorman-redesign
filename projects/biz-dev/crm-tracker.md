# Blue Canvas AI — CRM & Outreach Tracking

## Recommendation: Google Sheets

**Why Google Sheets (not Notion, not a CRM tool):**
- PJ already uses Google. Zero learning curve.
- Accessible from phone (check replies on the go)
- Free. No subscription.
- Shareable if you hire help later.
- Can't over-engineer it. That's a feature.

**When to upgrade:** When you hit 50+ active leads or hire a salesperson. Then look at HubSpot Free CRM.

## Google Sheet Template

Create a new Google Sheet called **"Blue Canvas — Outreach Tracker"**

### Tab 1: Lead Pipeline

| Column | What goes here |
|--------|---------------|
| **A: Business Name** | Company name |
| **B: Contact Name** | Decision maker's name |
| **C: Sector** | Estate Agent / Solicitor / Healthcare / Trades / Other |
| **D: Location** | Derry / Letterkenny / Strabane / etc |
| **E: Website** | URL |
| **F: Lead Score** | 1-10 (see lead-scoring.md) |
| **G: Key Issue** | Site down / Slow / No GBP / Competitor gap |
| **H: Source** | Local Scraper / Apollo / Manual / Referral |
| **I: Showcase URL** | Link to generated showcase |
| **J: Email Sent** | Date + template used (e.g., "12/3 — Template A") |
| **K: LinkedIn Sent** | Date of connection request |
| **L: Follow-Up Sent** | Date of follow-up |
| **M: Status** | New / Contacted / Replied / Call Booked / Proposal Sent / Won / Lost / Cold |
| **N: Next Action** | What to do next + when |
| **O: Notes** | Anything useful |
| **P: Revenue** | Monthly value if won |

**Colour coding for Status:**
- 🟢 Green = Won
- 🔵 Blue = Call Booked / Proposal Sent
- 🟡 Yellow = Contacted / Replied
- ⚪ White = New
- 🔴 Red = Lost
- ⚫ Grey = Cold (revisit in 30 days)

## Daily Tracking Habit

**Takes 2 minutes. Do it immediately after each outreach session.**

1. For each person you contacted today: fill in columns J-N
2. For any replies received: update Status column
3. For any calls booked: add to calendar + update Status

**The sheet is your single source of truth.** If it's not in the sheet, it didn't happen.

---

## Setup Instructions

1. Open Google Sheets → New spreadsheet
2. Name it "Blue Canvas — Outreach Tracker"
3. Create 3 tabs: "Lead Pipeline", "Weekly Dashboard", "Won Clients"
4. Copy the column headers above
5. Add conditional formatting on column M (Status) for colour coding
6. Bookmark it. Pin the tab. Put it on your phone home screen.
7. **Pre-populate with the 12 leads from the local scraper**
