# Blue Canvas AI — Daily Outreach Playbook

**Time required:** 30-60 minutes
**When:** Every weekday, 9:00-10:00 AM
**Goal:** 5 new contacts per day = 25/week = 100/month

---

## Morning Routine (30-60 mins)

### Step 1 — Check Pipeline (5 mins)

- [ ] Open the **CRM tracker** (Google Sheet — see `crm-tracker.md`)
- [ ] Check for any replies from yesterday's outreach
- [ ] Check Apollo dashboard for new leads
- [ ] Ask Albie: "Any new leads from the local scraper?"

**Action:** Move any replies to the appropriate stage (Replied / Call Booked / Not Interested)

### Step 2 — Pick 5 Targets (5 mins)

From the lead pipeline, pick 5 businesses to contact today. Prioritise by lead score:

| Score | Criteria | Priority |
|-------|----------|----------|
| 🔴 9-10 | Site down/404, no web presence at all | Contact TODAY |
| 🟠 7-8 | PageSpeed <50, no GBP listing | Contact this week |
| 🟡 5-6 | Competitor gap, outdated site | Contact when pipeline is thin |
| 🟢 1-4 | Decent site, minor issues | Low priority / nurture |

**Pick mix:** 2-3 high score + 1-2 medium score. Don't waste all hot leads in one day.

### Step 3 — Build Showcases (10-15 mins)

For each target, ask Albie to build a showcase:
> "Build a showcase for [BUSINESS_NAME] — they're a [SERVICE_TYPE] in [LOCATION], website is [URL]"

This generates a personalised interactive presentation deployed to GitHub Pages.

**While showcases build:** Move to Step 4 for businesses you already have showcases for.

### Step 4 — Send Emails (10 mins)

For each target:
1. Open **email-templates.md** — pick the right template based on their problem
2. **Personalise everything** — replace all [PLACEHOLDERS]
3. Drop in the showcase URL
4. Send from phil@bluecanvas.ai
5. Log in CRM tracker: date, template used, showcase URL

**Template selection guide:**
- Site broken → Template A
- Slow site → Template B
- Competitors outranking → Template C
- Good candidate for DTFF → Template D
- Already emailed 7 days ago → Template E

### Step 5 — LinkedIn (5-10 mins)

For each target:
1. Find the business owner / decision maker on LinkedIn
2. **Like/comment on 2-3 of their recent posts** (if they post)
3. Send connection request with note (see `linkedin-templates.md`)
4. Log in CRM tracker

**LinkedIn limits:** Max 5 new connection requests per day. Don't exceed this.

### Step 6 — Follow Up (5 mins)

Check CRM tracker for:
- [ ] Emails sent 7 days ago with no reply → Send Template E
- [ ] LinkedIn connections accepted with no message sent → Send first message
- [ ] LinkedIn first messages with no reply (7 days) → Send follow-up message
- [ ] Any "warm" leads that need a nudge

**One follow-up per channel.** If they ignore email + LinkedIn follow-up = move to "Cold" and revisit in 30 days.

### Step 7 — Update Tracker (2 mins)

- [ ] Log all today's activity in CRM tracker
- [ ] Update lead scores if new info discovered
- [ ] Note any leads to follow up next week
- [ ] Count: emails sent, connections made, replies received

---

## Weekly Review (Friday, 15 mins)

Every Friday, review the week:

- **Sent:** How many emails + LinkedIn messages?
- **Replies:** How many responded?
- **Calls booked:** How many took a call?
- **Proposals:** How many got a proposal?
- **Closed:** Any new clients?

**Target conversion funnel:**
- 25 contacts/week → 5-8 replies → 2-3 calls → 1 proposal → close 1 every 2-3 weeks

**Ask Albie:** "Run the local lead scraper for [AREA/SECTOR]" to refresh the pipeline.

---

## Monthly Pipeline Refresh

- Ask Albie to run the local scraper for new areas (Letterkenny, Strabane, Limavady, Coleraine)
- Review Apollo lead gen results
- Expand into new sectors if current ones are tapped out
- Update sector packages based on what's converting
