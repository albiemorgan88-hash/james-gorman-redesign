# James Gorman SEO

Work on **James Gorman Property SEO only**.

## Non-negotiables

- **Draft only. Never publish directly.**
- **Never make external/public changes** (site edits, GBP changes, directory submissions, social/profile edits) without Phil’s explicit go-ahead.
- **Document every run** in the client files under `projects/clients/james-gorman/`.
- Update both:
  - `seo-changelog.md`
  - `backlog.md`
- Keep recommendations practical, prioritised, and easy for Phil to publish manually.

## Working files

Use these files every run:

- `projects/clients/james-gorman/README.md`
- `projects/clients/james-gorman/seo-changelog.md`
- `projects/clients/james-gorman/backlog.md`
- `projects/clients/james-gorman/weekly-report-template.md`
- `projects/clients/james-gorman/wix-access.md`
- `projects/clients/james-gorman/run-seo-pass.md`

## Priority order

Work in this order unless Phil says otherwise:

1. **Website technical SEO**
   - crawl/indexation blockers
   - broken/wrong URLs
   - title/meta/H1 gaps
   - internal linking
   - mobile UX/performance issues
   - schema opportunities
2. **Google Business Profile**
   - existence/status check
   - setup/verification plan
   - category/services/photo/review plan
3. **Search visibility / citations / content**
   - directory citations
   - local landing page ideas
   - blog/content briefs
   - FAQ/schema ideas
   - backlink and mention opportunities

## Default run workflow

1. Read `README.md`, `backlog.md`, and the latest entries in `seo-changelog.md`.
2. Review the current site/search situation as needed.
3. Draft the next best SEO fixes or recommendations.
4. Record outcomes clearly:
   - append dated changelog notes
   - update backlog status / next actions
   - prepare or update report notes if relevant
5. Leave clear handoff notes for Phil.

## Output standard

Prefer concise deliverables such as:

- page-by-page metadata drafts
- slug recommendations
- internal linking suggestions
- content briefs
- GBP setup/checklist drafts
- citation target lists
- weekly report drafts
- prioritised fix lists with impact + effort

For each recommendation, include where possible:

- **What**
- **Why it matters**
- **Priority** (`P1`, `P2`, `P3`)
- **Who does it** (`Phil publish`, `Needs client input`, `Agent draft only`)
