## Content Execution Pipeline

### How Content Works

The site uses Next.js dynamic routes with data files:
- **Career guides:** `src/app/careers/[slug]/page.tsx` renders from `src/data/guides.ts`
- **Location pages:** `src/app/locations/[slug]/` renders from `src/data/locations.ts`
- **Job listings:** `src/app/job/[slug]/` renders from `src/data/jobs.ts` / `jobs.json`

To add new content, add entries to the data files → build → deploy. No new route files needed.

### Adding a Career Guide

1. Research keywords via Ahrefs (team access) — target 500+ monthly volume
2. Add entry to `src/data/guides.ts` following existing format:
   - slug, title, metaTitle, metaDescription
   - sections: intro, day-in-the-life, salary data, qualifications, career path, FAQs
   - Schema: FAQPage markup (auto-generated by `[slug]/page.tsx`)
3. Run `npm run build` to verify
4. Deploy:
   ```bash
   source ~/.zprofile && cd /Users/philsagent/.openclaw/workspace/projects/uk-trade-jobs && npx vercel --token "$VERCEL_TOKEN" --yes --prod
   ```

### Adding a Location Page

1. Research "[trade] jobs [city]" keywords via Ahrefs
2. Add entry to `src/data/locations.ts`:
   - slug, city, region, metaTitle, metaDescription
   - Local salary data, major employers, job market overview
3. Build and deploy as above

### Adding Job Listings

1. Add to `src/data/jobs.ts` with JobPosting schema fields:
   - title, company, location, salary, description, datePosted
2. Build and deploy

### Batch Content Creation (SEO Engine Integration)

When seo-engine identifies content opportunities for UKTJ:

1. Receive keyword list with search volume and difficulty
2. Prioritise: volume >500, difficulty <40
3. Create content entries in batches of 5-10
4. Each entry must include: unique meta title/description, 1500+ words, FAQ section (5+ questions), salary data from ONS/Glassdoor
5. Build, test locally, deploy to Vercel
6. Submit new URLs to GSC for indexing:
   ```bash
   source ~/.zprofile && curl "https://www.googleapis.com/webmasters/v3/sites/https%3A%2F%2Fuktradejobs.com/urlNotifications:publish" \
     -H "Authorization: Bearer $GSC_TOKEN" \
     -H "Content-Type: application/json" \
     -d '{"url":"https://uktradejobs.com/careers/[slug]","type":"URL_UPDATED"}'
   ```
